# MH auditoria tecnica del Remix version 3

Estoy definiendo la arquitectura del MVP de una plataforma llamada Mallorca Holística.

NO quiero diseño visual.
NO quiero colores.
NO quiero imágenes.
NO quiero componentes sofisticados.
NO quiero que tomes decisiones de producto.

Quiero únicamente wireframes funcionales y navegación entre pantallas para validar el recorrido del usuario.

Actúa como un UX Architect.

Objetivo:
Ayudarme a validar si el flujo de incorporación tiene sentido antes de invertir tiempo en diseño y programación.

Crea únicamente wireframes simples con botones navegables.

IMPORTANTE

Antes de generar los wireframes analiza el flujo completo y señala:

Posibles pasos innecesarios.

Posibles fricciones para el usuario.

Pantallas que podrían fusionarse.

Mejoras de UX.

Dudas que debería resolver antes de programar.

Prioriza simplicidad extrema.
No añadas funcionalidades nuevas.
No añadas automatizaciones.
